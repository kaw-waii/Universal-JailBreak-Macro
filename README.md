# Universal-JailBreak-Macro

SETUP:
click on the green code button, press download zip

depends on ahk v2 being installed https://www.autohotkey.com/ 

once you've installed AutoHotkey
  ->unzip the folder
  ->navigate to 'Universal JailBreak macro v1.ahk' and double click it
  ->this file is your macro; you will need to open it every time you want to use it

drop pistol before using if the macro equips it
